**Pre-release 0.8.9**.

- **Manufacturer keys in auto-configuration**: when the run finishes, a line under the best mode lists the manufacturer keys the camera exposes beyond standard Android, grouped by namespace, with how many can be used when the camera session opens. It shows at a glance whether a phone hides extra modes behind its own keys, the first step to using everything the hardware can do.

### What to test
1. Run auto-configuration and check the line under the best mode: either the key groups (`namespace listed/session`) or that the camera lists none.
