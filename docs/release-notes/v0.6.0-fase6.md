**Phases 0–5 closed, Phase 6 (multicamera) started** (pre-release; leftovers in docs/PROGRESS.md › Phase status, D54).

### New since v0.0.5-fase0
- **Auto-configuration**: offered at first start (skippable) and in Settings › Auto-configuration. It records each mode for a few seconds and keeps the modes this phone really holds (Pixel 8: 4K30 10-bit best, 4K60 8-bit holds, 4K60 10-bit refused). It refuses to measure a hot phone.
- **Orientation**: both landscapes were upside down on every phone (seen on the OPPO); fixed. Tap-to-focus follows the same rule.
- **Health**: battery %, temperature °C, minutes left always on screen; banner when battery, storage or heat will run out within minutes ("Batería para ~8 min", "Se calentará en ~3 min"), with a vibration on critical (switch in Settings › Controls).
- **Colour**: UC-Log takes are tagged BT.2020 with an SDR transfer (no longer HLG), baked-LUT takes Rec.709.
- **Proxies** (Settings › Multicamera › Record proxy): 720p H.264 copy next to each take with the same audio; 10-bit takes get the monitor look. Second camera at the same time (experimental, phones that support it).
- **Timecode**: the separate WAV is a Broadcast Wave with the start time of day (Resolve / Premiere read it); on-screen timecode can show time of day.
- **Multicamera** (Multicam button on the camera screen): roles Camera / Monitor / Master, pairing by QR or 8-digit code (keys in the Android Keystore), monitor screen with live video, status, alerts and remote controls, master grid with REC all, proxy download from the monitor.
- UI: no more overlaps between banner, toasts and the status strip.

### What to test
1. Fresh install: the auto-configuration screen appears; run it with the phone cool and still. Check the best mode it proposes and that the mode list only shows measured modes.
2. Landscape both ways and portrait: preview upright, takes play upright, tap-to-focus lands under the finger.
3. Leave a take running 10+ minutes: watch the health line; heat or battery banners should appear before trouble.
4. With **two phones**: one in Camera role shows the QR, the other in Monitor role scans it; open the monitor: video, status, REC from the monitor, the camera's alerts on the monitor; switch off Wi-Fi on the monitor for 30 s while recording (the take must continue). With three phones: Master, REC all.
5. Proxy on: a `_proxy.mp4` appears next to each take; download it from the monitor's folder button.
6. UC-Log: the file is flat and a player no longer shows it as HDR.
