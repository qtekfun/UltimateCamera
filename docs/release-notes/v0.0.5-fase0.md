**First version that records** (pre-release, Phase 0 still open; Phase 2–5 features pulled forward, D22/D36). The camera is now the main screen; Diagnostics keeps the Phase 0 bench.

### New
- **Recording**: 4K / 1080p, 60/30 fps; HEVC 10-bit HLG BT.2020 by default, H.264 (8-bit) and AV1 where the phone has an encoder; AAC 48 kHz stereo; optional separate WAV. Modes the phone refuses fall to the next one (Pixel 8: 4K60 10-bit → 4K30 10-bit).
- **Portrait and landscape**, upright preview and files (rotation hint).
- **Photo mode** (small icon next to the settings gear); the app opens in the last mode used (Settings › Camera).
- **Manual controls** always on screen: ISO, shutter (180° button), WB presets / Kelvin, focus, EV, AE-L/AF-L; tap to focus and meter, long press to lock.
- **Colour**: LUT for the recording and a separate monitor LUT; UC-Log (10-bit) with a Rec.709 view on screen; LUT library with import and in-app download of maker LUTs.
- **Monitor tools** (preview only): zebras, false colour, peaking, frame lines, desqueeze, histogram / waveform / vectorscope.
- **Storage**: records to a connected USB drive or SD card automatically; tap the storage readout to choose Automatic / Phone / drive / folder. Write-speed test in Settings.
- **Status and safety**: battery, heat, dropped frames, bitrate, minutes left; a take stops cleanly (file saved) on critical heat, 3 % battery or full storage; volume keys start/stop.
- **New UI** design.

### What to test (Pixel 8 tested by the developer; please try others)
1. Install, open, allow camera and microphone. The preview must be upright in portrait and in both landscapes.
2. Record 30 s in portrait and 30 s in landscape; play both on the phone and on a computer: upright, sound in sync, no stutter.
3. Switch codec (H.264 / HEVC / AV1) and mode; record short takes.
4. Manual controls: change ISO and shutter; tap to focus on near and far objects; long press to lock.
5. LUT: pick UC-Log for the recording; the screen stays normal, the file is flat. Try a library LUT.
6. Monitor icon: zebras, peaking, a scope.
7. Plug a USB SSD or pendrive: the storage readout should switch to it; record; check the file on a computer (`Movies/UltimateCamera/`).
8. Photo mode: take photos in portrait and landscape.
9. Leave a long take (10+ minutes) running; watch heat and dropped frames.

Known issues: the auto-configuration wizard and the health forecast banner are not in this version yet; the storage readout in portrait can be truncated.
