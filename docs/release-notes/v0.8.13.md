**Pre-release 0.8.13**.

- **No more stretched selfie**: a camera asked for a size it does not list can deliver another size, which came out stretched. Before measuring such a size, auto-configuration now reads the size of the frames the camera really delivers. If it differs, the mode shows "gives another size · delivers WxH" and is not used. If it matches, the mode is measured as usual.
- Auto-configuration runs again on every phone, so a stretched mode found by 0.8.12 is no longer used.

### What to test
1. Run auto-configuration and check the "Front camera" section: a 4K mode the camera does not list should show the size it really delivers.
2. Switch to the selfie camera: the image must not be stretched.
