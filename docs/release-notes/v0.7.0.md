**Pre-release 0.7.0** (Phase 6, multicamera; first release under semantic versioning, D76).

- **Multicamera, redesigned**: pair two phones first (Show code / Scan code on either phone), then choose on either one which is the Camera and which the Monitor; swap roles or end the session without pairing again. A third phone can be the master of two cameras.
- **Monitor video**: the monitor shows the camera's live image (small preview stream, so the take keeps its frame rate). Pairing and starting video no longer crash the app (missing network-state permission for the video link).
- **Crash reports**: Diagnostics › Crash reports keeps the last crashes (also native ones, from Android's exit records) to share or copy. No personal data.
- **Frame rate**: streams always ask the camera for a fixed rate (e.g. 60–60) first; auto-configuration tells "camera ran slower" from dropped frames and no longer marks 4K60 as failing from it (vivo X500 Pro Max).
- **Photos**: high-quality still processing, a base rendering with black point, local contrast and adaptive saturation (closer to the phone's own camera), the HDR method written in the photo's metadata. HDR fusion runs on the GPU and is toned to the normal exposure (no more dark fusion photos); it stays manual-only for now.
- **Colour styles**: Standard, Rich contrast, Vibrant, Warm, Cool, Natural, Soft film, Faded, Mono and Mono contrast, adjustable (tone × warmth pad, palette, intensity), for photos (style chip) and video (LUT picker › Styles); defaults in Settings › Styles, optional unstyled copy of each photo.
- **Portrait (experimental, off by default)**: never hangs when depth frames are missing; saved as a normal photo instead.

### What to test
1. Two phones on the same Wi-Fi: Multicam on both → Show code on one, Scan code on the other → choose Camera on one → the other shows live video; REC from the monitor; Swap roles.
2. If anything crashes: reopen the app → Diagnostics → Crash reports → Share.
3. vivo: run auto-configuration again (Settings) indoors: 1080p60 should hold at 60 fps and the 4K60 rows be probed.
4. Styles: pick a few in photo mode and for a recording (8-bit and 10-bit).
5. Photos next to the phone's own camera (same scene): colour and contrast; one Fusion photo (time it).
