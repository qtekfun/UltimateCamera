**Phase 0 spike** (pre-release). Test bench to measure each phone before the real camera is built; it does not record usable videos yet.

### What to test on each phone (OPPO, vivo, Xiaomi, Honor, Pixel)
1. Install the APK (`adb install -r ultimatecamera-0.0.2-fase0.apk`, or open it on the phone). Optionally check the signature with `apksigner verify --print-certs` against the certificate digest below.
2. Open **UltimateCamera**, allow camera and microphone. Keep it unplugged from the charger (charging heats the phone and skews the thermal data), screen on, in landscape, on a table at room temperature.
3. Connect what you have: USB microphone, Bluetooth headset/microphone (SCO or LE Audio).
4. Tap **Run everything** (capabilities, pipeline matrix ~5 min, concurrent cameras, audio inputs). Do not leave the app.
5. Tap **Sustained 4K60 (5 min)** for the thermal test.
6. Network: on a computer in the same Wi-Fi run `python3 scripts/spike/udp_echo.py` (or tap *Start echo server* on another phone) and measure with its IP; repeat with the second phone as a hotspot.
7. With two phones: *Be the camera* on one, *Be the monitor* on the other with the first one's IP (Wi-Fi router, then each phone as hotspot). Both export their report.
8. Tap **Export report** and send me the JSON from `Download/UltimateCamera-spike/`.

Details: `docs/TESTING.md` (manual and adb-automated runs) and `docs/spike-report.md` (what is measured).

APK SHA-256 is in the attached `.sha256` file.
