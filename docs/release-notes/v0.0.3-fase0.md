**Phase 0 spike** (pre-release), first release signed with the project key. Test bench to measure each phone before the real camera is built; it does not record usable videos yet.

New since v0.0.2-fase0 (never published, D18): home screen with **Diagnostics** (the spike bench) and **Settings** (maximum brightness, off by default; app language; feature groups); session parameters so the HAL picks the right sensor mode for 60 fps, and configurations the camera refuses are reported (`sessionRejected`); 4K60 8-bit + LUT added to the matrix and as the sustained-run fallback.

### What to test on each phone (OPPO, vivo, Xiaomi, Honor, Pixel)
1. Install the APK (`adb install -r ultimatecamera-0.0.3-fase0.apk`, or open it on the phone). Check the signature with `apksigner verify --print-certs`: the certificate SHA-256 must be `711d378b96374de2181363dc9eb462c536322d942adadba34d2f535d689f245d`.
2. Open **UltimateCamera** → **Diagnostics**, allow camera and microphone. Unplugged from the charger, screen on, landscape, on a table at room temperature, **the back camera facing a lit, detailed scene** (a dark scene makes the encoder idle and skews the results).
3. Connect what you have: USB microphone, Bluetooth headset/microphone (SCO or LE Audio).
4. Tap **Run everything** (capabilities, pipeline matrix ~5 min, concurrent cameras, audio inputs). Do not leave the app.
5. Tap **Sustained 4K60 (5 min)** for the thermal test (it falls back to 4K60 8-bit if the camera refuses 10-bit at 60 fps, as the Pixel 8 does).
6. Network: on a computer in the same Wi-Fi run `python3 scripts/spike/udp_echo.py` (or tap *Start echo server* on another phone) and measure with its IP; repeat with the second phone as a hotspot.
7. With two phones: *Be the camera* on one, *Be the monitor* on the other with the first one's IP (Wi-Fi router, then each phone as hotspot). Both export their report.
8. Tap **Export report** and send me the JSON from `Download/UltimateCamera-spike/`.
9. Settings: maximum brightness off at first launch; on → full brightness, kept after closing the app; *Choose language* switches English/Spanish.

Details: `docs/TESTING.md` (manual and adb-automated runs) and `docs/spike-report.md` (what is measured, Pixel 8 results).

APK SHA-256 is in the attached `.sha256` file.
